# Tri-Valley Readers

Website for Tri-Valley Readers, a women’s book club based in San Ramon, CA (East Bay). Live at [trivalleyreaders.com](https://trivalleyreaders.com).

## Pages

- **Home** (`index.html`) — Welcome, what the club does, and contact links
- **Reading List** (`reading-list.html`) — Currently reading, past reads with club reviews, and a wishlist
- **Featured Events** (`featured-events.html`) — Author visits and other special gatherings
- **Membership** (`membership.html`) — Who can join, what membership includes, and the signup form

## Tech

Static HTML, CSS, and a little JavaScript. Hosted on GitHub Pages with the custom domain `trivalleyreaders.com`.

`site.js` handles the mobile nav (and collapsible past events on small screens). The reading list page has its own script for tabs, the mobile section dropdown, and “read more” on reviews.
